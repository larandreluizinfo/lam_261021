# Jogo da Memória — Projeto LAM

Jogo da memória com 8 pares de cartas, contador de jogadas, cronômetro e botão para jogar de novo.

## 🎮 Como jogar

1. Clique em duas cartas para virá-las.
2. Se os emojis forem iguais, o par fica aberto.
3. Encontre os 8 pares no menor número de jogadas possível.
